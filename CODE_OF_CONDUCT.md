# Code of conduct

Velatura is a small, non-commercial community project. A few simple rules keep
it pleasant:

- **Be precise.** When you report a problem, say what you did, what you
  expected and what happened. A log line beats a guess.
- **Be kind.** People arrive from very different backgrounds and with very
  different hardware configurations.
- **Respect the licences.** Never commit model weights, never copy code from a
  project whose licence does not allow it (for example `sdnext-modernui`,
  which is AGPL-3.0), and always keep the attribution of the components you
  reuse.
- **Local means local.** Contributions must not add a cloud service, an
  account, an analytics endpoint or a telemetry call.

Reporting a problem: open an issue with the output of `velatura doctor`.
